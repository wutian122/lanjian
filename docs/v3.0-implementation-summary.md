### **方案 4：优化错误提示词**
- ✅ **第 1-2 次**：静默重试（不添加提示，避免污染上下文）
- ✅ **第 3-5 次**：添加简短友好的提示 + 格式示例
- ✅ **第 6+ 次**：提供详细指导 + 当前任务状态提示
- ✅ 提示词包含实际示例，而非生硬的要求

**对比**：

**旧提示词**（生硬）：
```
"请按照规定格式输出：Thought + Action + Action Input"
```

**新提示词**（友好 + 示例）：
```
请按照以下格式输出你的决策：

Thought: [你的思考过程]
Action: [动作名称，如 dispatch_agent、finish、summarize]
Action Input: [有效的JSON对象]

示例：
Thought: 我需要调度 verification Agent 来验证发现的漏洞
Action: dispatch_agent
Action Input: {"agent": "verification", "task": "验证 SSRF 漏洞"}
```

**文件**: `backend/app/services/agent/agents/orchestrator.py`

### **方案 11：审计追踪文件系统（新增）**
- ✅ 为每个任务生成独立的 Markdown + JSON 追踪文件
- ✅ 记录关键事件：Agent 调度、工具调用、漏洞发现、嵌入向量、上下文压缩、LLM 调用
- ✅ 实时统计：调度次数、Token 消耗、漏洞数量等
- ✅ 时间线展示：按时间顺序记录所有操作
- ✅ 供 AI 查阅的精简摘要（`get_summary_for_agent()`）
- ✅ 人类可读的 Markdown 格式
- ✅ 机器可解析的 JSON 格式

**存储结构**：
```
audit_traces/
├── fb10e9c0/                    # 任务 ID 前 8 位
│   ├── audit_trace.md           # Markdown 报告
│   ├── audit_trace.json         # JSON 数据
│   └── context_archive.json     # 上下文归档
```

**追踪内容**：
1. **Agent 调度**：agent 名称、任务、上下文长度、父 Agent
2. **工具调用**：工具名、输入参数、输出结果、耗时、成功状态
3. **漏洞发现**：类型、严重程度、标题、描述、位置、代码片段、PoC、发现者
4. **嵌入向量**：内容类型、向量数量、模型
5. **上下文压缩**：原始长度、压缩后长度、压缩方法、完整内容引用
6. **LLM 调用**：模型、Token 消耗、耗时、用途
7. **验证结果**：漏洞 ID、验证结果、证据、沙箱输出

**配置项**：
```python
audit_trace_enabled: bool = True
audit_trace_dir: str = "./audit_traces"
```

**文件**: `backend/app/services/agent/audit_trace.py` (新建)

## 🔄 集成到 Orchestrator

### **初始化阶段**
```python
# __init__ 方法中
self.trace_manager = AuditTraceManager(...)  # 创建追踪管理器
self.context_manager = ContextManager(...)   # 创建上下文管理器
```

### **主循环**
```python
# run 方法主循环中
# 1. LLM 调用前：上下文压缩
self._conversation_history = await self.context_manager.compress_if_needed(...)

# 2. LLM 调用：使用 Orchestrator 专用 Temperature
llm_output, tokens = await self.stream_llm_call(..., temperature=0.4)

# 3. 解析响应：增强容错性
step = self._parse_llm_response(llm_output)  # 使用新的解析器

# 4. 格式错误处理：智能重试策略
if not step:
    if retry_count <= 2:
        # 静默重试
    elif retry_count <= 5:
        # 添加友好提示 + 示例
    else:
        # 详细指导 + 状态提示
```

### **Agent 调度**
```python
# _dispatch_agent 方法中
# 1. 记录调度
self.trace_manager.add_agent_dispatch(agent_name, task, context)

# 2. 执行 Agent
result = await agent.run(sub_input)

# 3. 压缩输出（如果过长）
if len(output) > 100_000:
    compressed = await self.context_manager.compress_agent_output(...)

# 4. 记录漏洞发现
for finding in findings:
    self.trace_manager.add_finding(...)
```

### **任务完成**
```python
# finally 块中
self.trace_manager.finalize()  # 写入最终统计
```

- **当前**：连续 5 次格式错误 → 任务暂停（成功率 ~60%）

### **Token 消耗**
- **当前**：格式错误重试累积大量 Token

### **可观测性**
- **当前**：任务失败难以追溯原因
- **优化后**：完整的审计追踪文件 + 人类可读报告

## 📈 监控指标

### **需要关注的指标**
1. **格式错误率**：`format_error_count / total_llm_calls`
2. **任务暂停率**：`paused_tasks / total_tasks`
3. **上下文压缩频率**：`context_compression_count / total_tasks`
4. **平均 Token 消耗**：`total_tokens / total_tasks`
